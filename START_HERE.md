# Import this workspace

1. Extract the ZIP.
2. Open the FutureLife_Rehearsal folder in your editor, or open FutureLife_Rehearsal.code-workspace in VS Code.
3. With Python 3 installed, run: python3 -m http.server 8080 --directory dist
4. Open http://localhost:8080 in your browser.
5. Optional: with Node.js installed, run npm test. No npm install is needed.

The original hosting identity and Git metadata are excluded so you can import this as an independent project.

See README.md for implemented behavior and limitations. The AI interaction is simulated; no API keys, live model or financial-account connections are included.
